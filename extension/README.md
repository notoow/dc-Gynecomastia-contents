# 하이스트 탭 그룹 확장

1. ZIP 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions` 또는 Edge에 `edge://extensions`를 입력합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 하이스트 페이지를 새로고침하고 **새 그룹으로 열기**를 누릅니다.

현재 화면에 표시되는 원문 링크만 새 그룹으로 엽니다. 그룹명에는 출처와 선택한 게시월이 들어갑니다. 이 확장은 하이스트 GitHub Pages 주소에서만 동작하며 탭 그룹 권한만 사용합니다. 기존 탭은 변경하지 않습니다. 인앱 브라우저는 확장 설치를 지원하지 않을 수 있으므로 Chrome·Edge에서 사용하세요.
