# 하이스트 · 여유증 Q&A

## 유튜브 댓글 Q&A

`youtube.html`에 실제 YouTube Studio 댓글 19개를 선별했습니다. 질문 요약, 촬영 포인트, 원문 댓글 링크, 검색/주제 필터, 개별 PNG 다운로드와 전체 ZIP을 제공합니다. 2026-10-21 관련성순 목록에서 최근~약 5개월 전 댓글을 확인했으며 전수 수집은 아닙니다.

- 원본 캡처 PNG: 실제 Studio 화면을 댓글 단위로 자른 이미지. 흰 여백만 줄였습니다.
- 상단 댓글 편집기: 임의 아이디 생성, 직접 입력, 실제 댓글 불러오기, 프로필 사진 선택, 밝게/어둡게 테마, 배경 불투명도 0~100%, 투명 PNG, 크기 조절을 제공합니다. 원본 캡처와 편집 이미지는 구분됩니다.
- PNG는 2배 해상도로 생성합니다. 브라우저가 반복 다운로드를 차단하면 생성 이미지의 우클릭/길게 눌러 저장을 사용할 수 있습니다.
- 목록과 전체 ZIP은 실제 캡처만 제공합니다.
- 신규 의학 답변은 작성하지 않았으며 촬영 포인트는 원장님께 여쭐 질문입니다.
- `youtube.json` 수정 후 `python scripts/build_youtube.py` 실행. 원본 캡처 빌드에는 Pillow가 필요합니다.
- 원본 JPG, 생성 PNG, ZIP은 `assets/youtube/`에 있습니다.

## 디시인사이드 질문

황인성 원장의 촬영용 원페이지. 실제 디시인사이드 게시글 12개의 제목·원문 링크·예상 답변을 3열로 표시합니다. 히어로 영역 없이 질문 목록부터 보여줍니다.

- 제목 / 원문 링크: 해당 게시글을 새 탭에서 열기
- 게시글 전체 열기: 12개를 한 번에 열기. 브라우저에서 사이트의 팝업 허용 필요
- 차단 시: 차단된 링크 목록과 재시도 안내 제공
- 참고 자료 / 이용 안내: 답변 작성에 참고한 의학 자료 확인
- 작은 화면에서는 2열, 모바일에서는 1열. 인쇄용 스타일 포함

## 실행

빌드 도구나 외부 스크립트 없이 동작합니다. `index.html`을 직접 열거나 다음 명령으로 실행합니다.

```sh
python -m http.server 4173 --bind 127.0.0.1
```

## 내용 수정

`content.json`에서 제목, URL, 답변을 수정하고 정적 HTML을 다시 생성합니다.

```sh
python scripts/build.py
```

`index.html`은 생성 결과이며 함께 커밋합니다. 로고는 제공받은 하이스트 원본 PNG를 사용합니다.

## 출처와 작성 기준

2026-10-21 게시글 원문의 제목·본문·게시일 확인. 제목의 비속어를 포함해 원문 표기를 유지했습니다. 본문 전체나 회원 정보, 게시물 사진은 복제하지 않습니다. `content.json`에 확인한 맥락과 답변별 참고 자료를 기록했습니다.

예상 답변은 일반 의학 자료에 근거한 촬영 초안이며 원장님의 확정 답변이 아닙니다. 원문은 수정·삭제될 수 있으므로 촬영 전에 링크를 다시 확인하세요.

## 유튜브 댓글 인쇄

유튜브 페이지에서 댓글을 선택한 뒤 `선택 댓글 A4 병합 PDF`로 저장합니다. `실제 캡처 + 선명한 원문 텍스트`와 `실제 캡처만` 중 선택할 수 있습니다. 전체 19개 PDF도 바로 내려받을 수 있습니다. 기존 캡처 픽셀을 확대 복원한 것은 아니며, 인쇄 가독성은 별도의 임베디드 한글 텍스트로 보완합니다.

재생성: `python -m pip install Pillow reportlab pypdf` 후 `python scripts/build_youtube.py`. Windows 맑은 고딕(`C:/Windows/Fonts/malgun.ttf`)을 사용합니다. PDF 병합 라이브러리는 `assets/vendor`에 포함되어 외부 CDN 없이 실행됩니다.

## 확인한 동작

Microsoft Edge에서 1920×1080 / 1440×900 화면에 12개 질문 전체 표시, 태블릿·모바일 가로 넘침 없음, 개별 원문 이동, 전체 12개 새 탭 생성, 외부 탭의 opener 차단, 열린 탭 재사용, 팝업 차단 안내와 재시도, 참고 자료 대화상자 및 Escape 닫기를 확인했습니다. 원문 12개의 제목·게시일은 확인 당시 본문과 대조했습니다.

## 댓글 이미지 만들기

`comment-editor.html`은 독립 편집 페이지입니다. 각 페이지 헤더에서 접근하며, 유튜브 댓글의 ‘편집기에 불러오기’로 원문과 프로필을 가져올 수 있습니다. 편집기는 별도 빌드 없이 실행되고 PNG 다운로드·테마·투명 배경·프로필 업로드를 지원합니다.

편집기는 유튜브·인스타·디시 스타일 전환과 기본/랜덤/원본/모자이크/블러 프로필을 지원합니다. 랜덤 프로필은 브라우저에서 기하학 패턴으로 생성하며 업로드한 이미지는 서버로 전송하지 않습니다.
